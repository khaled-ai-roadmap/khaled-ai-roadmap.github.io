git clone ...

pip install -r requirements.txt
python src/train.py

قايمة جودة الـ Repo

  1. اسم واضح وصورة أو GIF للنتيجة في أول الـ README.
  2. requirements.txt بيشتغل على جهاز نضيف.
  3. مفيش مفاتيح API أو داتا حساسة في الكود (استخدم .env وملف .gitignore).
  4. اختبار واحد على الأقل وGitHub Action بيشغله.
  5. Commits صغيرة برسائل مفهومة بدل Commit واحد ضخم.
  6. قسم Results فيه مقارنة بـ baseline، وقسم Limitations بصراحة.
